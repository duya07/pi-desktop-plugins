密钥写入插件数据目录的 config.json（明文，权限 600）。宿主给插件进程的是最小环境（PATH/TEMP/HOME 一类），读不到你自己的环境变量，所以这里没有 env 来源。

模型

通道 pin（对后续请求立即生效）

通道列表来自“探测通道”：网关故意 pin 一个不存在的通道，让路由器在花掉 token 前把所有可用通道报出来。校验会把每个通道逐个 pin 一次并记录结论。

模型参数（自填 + 注册）

这里改的是宿主读的那份 manifest：只有勾上「注册」的模型才会出现在宿主的模型选择器里，未注册的模型只在网关里存在（选中它发请求仍可用，但宿主的模型列表里看不到）。另外注意：宿主里若已存在同 id 的「自建」provider 模型，请求可能由它直接服务而不经过本网关 —— 那些请求在 pin、账号池和用量里都看不到（看「用量」页有没有数据就能判断）。 保存只提交改动过的字段。注意：宿主 provider 行只在插件安装/启用（或宿主启动）时同步，实测开发热重载**不会**刷新它 —— 保存后要让新参数/新模型真的进模型选择器，请到插件页把本插件停用再启用（或重启 PI-Desktop）。
「已改」= 这个字段被本面板覆盖过；「官方值」= Cline 目录里的值，只作对照，不会自动回写。档位控件来自目录：effort 是滑杆、toggle 是开关、none 表示该模型没有思考档位。

官方额度

数字来自 Cline 官方接口 GET /users/me/plan/usage-limits，显示的是该账号的已用比例（条长=已用，≥90% 红、≥70% 橙）； 和下面「用量」那张卡的本地账本不是一个口径 —— 账本只统计经过本网关的请求，官方额度里还包含这个账号在别处用掉的量。 只列插件读得到密钥的账号（「账号池」里那几条内联账号）：模型设置页那把密钥（host）只活在请求内存里，读不到，所以不在这里出现。

用量

账本里的数字只来自上游每次响应最终帧的 usage —— 官方额度是 Cline 官方按账号给的（见上方「官方额度」卡片），和这里不是同一个口径。没有成本时显示「—」； 「有成本记录」是窗口内带成本的请求占比，形如 3/10。按天分组用的是 UTC 日期，明细里的时间显示为本机时区。

网关设置

怎么用

1. 到“设置 → 模型 / Providers”，找到本插件声明的 provider「Cline Pass（本地网关）」，填入 Cline API Key（这把 key 会作为 host 账号参与池）。
2. 在模型选择里选 cline-pass/* 的模型；请求会经本机网关转发到上游，pin / failover / 账号轮询都在网关里生效。
3. 网关只监听 127.0.0.1；插件卸载或禁用时端口会被释放。
